# ハナウタ作曲室

鼻歌を歌うと、メロディを読みとって、ドラム・ベース・和音をつけて1曲にするブラウザのアプリ（1ファイル、ライブラリなし）。

## しくみ
- 録音：MediaRecorder で録って、終わってから decodeAudioData。録音中は AnalyserNode でいまの高さを表示
- 高さ：11025Hz に落として、512サンプルの窓・128ずつずらしながら YIN（自己相関の一種）で基本周波数を出す
- 音符にする：オクターブの飛びをならす → 中央値でなめらかに → 高さが 0.75 半音以上変わるか、音量が 3割以下に下がったら区切る（70ms 未満は捨てる）
- 調：Krumhansl の重みとの相関。音を調の音にそろえる
- テンポ：70〜140 の中で、音の始まりが8分音符のマスに一番そろうもの。8分音符のマスにそろえる
- 和音：小節ごとに、よく使う6つの三和音から、メロディの音（強拍は重め）に合うものを選ぶ。はじめと終わりは主和音、終わりの前は属和音を少し優先
- 伴奏：ロック／ローファイ／8bit／バラード。WebAudio のオシレーターとノイズで合成。WAV は OfflineAudioContext で書き出す
- 保存：見る人のブラウザ（localStorage）。録った声は保存しない
